## 📖 Про проєкт

Початково цей проєкт створювався як університетська лабораторна робота для вивчення проблем конкурентного доступу до даних. 

У **2026 році** код пройшов **Refactoring & Modernization**, щоб відповідати сучасним Enterprise-стандартам розробки на C#.

### 🛠 Що було покращено (Modernization 2026):
1. **Міграція на Task Parallel Library (TPL):** Усі "сирі" потоки `Thread` було замінено на сучасні завдання `Task.Run()`, які автоматично керуються пулом потоків (ThreadPool), що робить програму швидшою та легшою для пам'яті.
2. **Clean Architecture:** Програма розділена на логічні шари (`UI`, `Services`, `Core`). Жодного монолітного коду у `Program.cs` — лише чисте налаштування залежностей.
3. **Потокобезпечність (Thread Safety):** Глобальні статичні масиви видалені на користь передачі стану через параметри. Для спільного доступу до єдиного ресурсу (консолі) інтегровано жорстку синхронізацію через `lock`, щоб уникнути змішування тексту.
4. **Оптимізація випадкових чисел:** Використано швидкий, статичний і потокобезпечний `Random.Shared`.
5. **Візуальна естетика (Spectre.Console):** Стандартний консольний вивід повністю замінено на кольорове та динамічне відображення завдяки потужній бібліотеці `Spectre.Console`.

## 🎯 Як це працює під капотом?

Програма генерує масив з 10 випадкових чисел і паралельно запускає два завдання (`Task`):

| Потік | Колір | Завдання |
| :--- | :--- | :--- |
| **T0** | 🟦 Cyan | Знайти найбільше серед перших 5 елементів масиву |
| **T1** | 🟨 Yellow | Знайти найбільше серед останніх 5 елементів масиву |

Обидва потоки намагаються одночасно виводити інформацію про кожен проаналізований елемент на екран. Завдяки використанню `lock`, вивід синхронізується, і ми бачимо, як потоки по черзі (без "зламаних" рядків) звітують про свою роботу.

## 🚀 Як запустити?

1. Переконайтесь, що встановлено **.NET 8 SDK**.
2. Клонуйте репозиторій та перейдіть у папку:
   ```bash
   git clone https://github.com/Lutvunenko-Dmutro/SharedResourcesShowcase.git
   cd SharedResourcesShowcase
   ```
3. Запустіть проєкт:
   ```bash
   dotnet run
   ```
